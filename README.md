## ⚡ 这是什么

以三元结构理论（三维 × 八阶 × 六类利益）为内核的结构化分析工具。输入政策文件、社会事件、组织资料或舆论场的相关文本，产出带来源标注的结构化报告，可导出 Word / PDF / 交互式 HTML / PPT。

分析方法是固定的：拆结构、约束输出、规范格式都写在框架里，同一份输入不会因为换一次对话就得到完全不同的结果。方法论、渲染器、利益关系网络图的代码全部开源，每一步怎么做的都可以审查。

> 已有 12+ 份真实案例报告验证（商标法修订、一人公司政策、胖猫事件舆论博弈、蜜雪冰城组织诊断等），均由 AI Agent 在框架约束下自动产出，脚本见 `cases/` 目录。

## 🧭 四种分析模式

| 模式        | 结构             | 适用对象       |
| --------- | -------------- | ---------- |
| 政策分析      | 8 段式           | 法规、文件、制度文本 |
| 事件 / 案例分析 | 5 段式 / 深度 8 段式 | 社会事件、舆论热点  |
| 组织诊断      | 9 段式           | 组织、公司、机构   |
| 舆情分析      | 7 段式           | 舆论场、叙事竞争   |

支持**组合分析**：多模式章节按书写源序拼接，一份报告同时覆盖舆情 + 组织 + 政策多个维度。

## 🎯 核心能力

1. **利益关系网络** —— vis-network 关系图：力导向 / 环形分组 / 地理布局三种排布，支持利益类型、属地、强度阈值、关系状态四个维度筛选；节点大小 = 证据数、边宽 = 关系强度、跨省关系虚线标记，点开节点可查立场与逐条证据
2. **写作规范校验** —— 内核强制校验输出：禁 EVD 编号、禁机械分层、禁套话，保证格式与质量的下限
3. **版本留痕** —— 每次生成留存版本，可回溯、可编辑、可下载
4. **联网检索降级链** —— BING → Brave → DuckDuckGo，零 Key 也能检索
5. **BYOK 架构** —— 访客自带 API Key，服务器不持有、不存储任何模型密钥，部署方零密钥成本、零额度风险

## 🏗️ 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                  Next.js 15 前端工作台                     │
│   分析 / 项目 / 报告 / 利益网络 / 设置 / 实时进度 (WebSocket) │
└───────────────┬─────────────────────────┬────────────────┘
                │ /api                    │ /ws
┌───────────────▼─────────────────────────▼────────────────┐
│               FastAPI 后端（SQLite）                       │
│   任务队列 · 联网检索 · 提示词装配 · 契约校验 · 版本留痕        │
└───────────────┬───────────────────────────────────────────┘
                │ engine.export_from_text()
┌───────────────▼───────────────────────────────────────────┐
│          分析内核（纯 Python，可独立运行）                   │
│   parser → 三元结构分析 → docx / pdf / viz_network          │
└───────────────────────────────────────────────────────────┘
```

- 前端 / 后端 / 内核三层解耦：内核可以脱离 Web 独立使用
- 单容器 Docker 部署（Caddy 反代），支持 Render Blueprint 一键上线

## 🚀 快速开始

### 1 · 本地工作台（Windows）

**Windows 上零门槛启动：双击项目根目录的 `启动工作台.bat`**

脚本会自动先关掉旧进程，再起新的前端 + 后端，所以改完代码后再双击一次就能看到新效果。

| 入口        | 地址                           |
| --------- | ---------------------------- |
| 前端工作台     | `http://127.0.0.1:3000`      |
| 后端 API 文档 | `http://127.0.0.1:8000/docs` |

### 2 · 命令行内核（纯 Python）

```python
from engine import export_from_text

export_from_text(markdown_text, title="你的分析标题")
```
